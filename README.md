# City Router

A command-line tool where you build your own city graph (undirected)
and then use different functions on it.

## Features

The program gives you 7 options:

1. Add a new city to your graph.
2. Add a road between two cities.
3. See your full graph as it is now.
4. Find the shortest path between two cities (fewest roads).
5. Check if any connection exists between two cities.
6. See all possible paths between two cities (up to 100 paths by default).
7. Exit the program.

## How to Run

You need Python 3.6 or newer installed on your computer.
No extra libraries are needed.

1. Open the terminal in the folder where this file is saved.
2. Run this command:

```
python city_router.py
```

## Concepts Used

- dict and set: to build the graph (adjacency list)
- BFS: to find the shortest path
- DFS (iterative): to check if a path exists
- Backtracking: to find all paths between two cities with DFS

Libraries:

- `pathlib` (Path): to handle the location where the graph file is saved and loaded
- `pickle`: to save the graph to a file as bytes and load it back into memory
- `collections` (deque): to make queue pop O(1) in the shortest path search
- `time`: to rename a corrupted graph file by adding the time to its name

## Notes

- Your graph file is saved here: `home folder / Anas_graph / graph.txt`
- Do not edit this file by hand. If the file gets corrupted, the program
  renames the old file and creates a new empty graph file.
- Only load graph files that you created yourself. A pickle file from an
  unknown source can be unsafe.
- You can change the all-paths limit. Open the code file, search for
  `allpaths_limit`, and change the number to the limit you want.
